================== 1 этап (загрузка, анализ, извлечение) =====================
Сначала в систему загружаются файлы:
1. Только doc/docx файл (внутри описательная часть, характеристики, планировки в виде картинок)
2. ТЗ doc/docx + планировка (dwg/pdf/image) -> приводим к pdf перед загрузкой
3. ТЗ doc/docx + планировка ((dwg/pdf/image) + характеристики в (excel/pdf/image)) -> приводим к pdf перед загрузкой

Планировка может содержать информацию о грузооборотах, хранимой продукции, температурных режимах, архитектурные сведения.
Почти во всех случаях габаритная информация находится на планировке

Подготовка файлов к отправке, выбор промпта (пока 1 вариант, без выбора)
Можно рассмотреть мультимодельный подход (например, одинаковый запрос в разные LLM (Claude, OpenAI, Gemeni, Grok))
и потом мерж результатов.

Какие данные нужно извлечь для 1 этапа:
1. длина (А, В)
2. ширина (Б, Г)
3. высота
4. площадь (расчет из д * ш) (калькуляция вне llm)
5. площадь (расчет из д * ш * в) (калькуляция вне llm)
6. материал теплоизоляции (А, Б, В, Г, Потолок, Пол)
7. толщина теплоизоляции (А, Б, В, Г, Потолок, Пол)
8. температуры внешние (А, Б, В, Г, Потолок, Пол)
9. тип хранимой продукции 
10. температура входящего продукта
11. конечная температура продукта
12. температура и влажность в камере
13. время процесса охлаждения
14. время работы погрузочной техники
15. оборот хранимой продукции в сутки
16. масса продукта в камере
17. кратность вентиляции (приток, вытяжка)
18. температура и влажность приточного воздуха
19. наличие и тип рекуперации/дополнительно охлаждения приточного воздуха
20. количество дверей/ворот/доков в камеру
21. размеры дверей/ворот/доков
22. время открытия дверей/ворот/доков
23. температура за открытыми дверями/воротами/доками
24. наличие занавеса, штор ПВХ, тепловых завес для дверей/ворот/доков
25. количество работающих в камере
26. тип и наличие освещения
27. тип и количество погрузочно-транспортных средств
28. тип и количество электрических устройств

Провести валидацию полученных данных.
Извлечь из ответа данные в формате, возможном для арифметических и булевых операций в модуле калькуляции

================== 2 этап (валидация полученных данных менеджером) =====================

После загрузки в приложение файлов с ТЗ, открывается страница в формате таблицы, в которой по каждой камере заполнены данные из
анализа, либо пустые ячейки, подсвеченные красным. При наведении на ячейку выводится сообщение "Данные нераспознаны" и есть
возможно для ввода незаполненных ячеек, либо редактированием заполненных. Также для каждой камеры есть чекбокс "учесть в расчете"
