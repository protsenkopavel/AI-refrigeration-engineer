В каком виде приходит задание?
1. Только doc/docx файл (внутри описательная часть, характеристики, планировки в виде картинок)
2. ТЗ doc/docx + планировка (dwg/pdf/image) -> приводим к pdf перед загрузкой
3. ТЗ doc/docx + планировка ((dwg/pdf/image) + характеристики в (excel/pdf/image)) -> приводим к pdf перед загрузкой

Планировка может содержать информацию о грузооборотах, хранимой продукции, температурных режимах, архитектурные сведения.
Почти во всех случаях габаритная информация находится на планировке
